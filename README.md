# Bengi Albukrek

I'm building [Deflows](https://deflows.com/?utm_source=github&utm_medium=profile&utm_campaign=bengialb), a platform for understanding, documenting, and converting visual ETL flows.

It reads Tableau Prep, Power Query, Alteryx, and SSIS files so teams can inspect the logic, generate documentation, and convert supported transformations into code.

PostgreSQL conversion is live. Other conversion targets are in beta.

My work focuses on flow parsing, code generation, and making ETL migrations easier to check.
